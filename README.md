# Блеф — игра для свадеб и корпоративов

Гости придумывают правдоподобную ложь про героев вечера, а потом ищут правду среди чужих выдумок. Большой экран (проектор или ТВ) показывает вопросы и раскрытие, гости играют со своих телефонов через браузер: ничего устанавливать не нужно.

## Запуск на своём ноутбуке

Нужен Node.js 18 или новее (https://nodejs.org).

```bash
npm install
npm start
```

В консоли появятся два адреса:
- **Экран ведущего**: `http://localhost:3000/host.html`. Откройте его на ноутбуке, подключённом к проектору, и нажмите «На весь экран».
- **Для гостей**: адрес вида `http://192.168.x.x:3000/play.html`. QR-код на экране ведёт именно туда.

Ноутбук и телефоны гостей должны быть в **одной Wi‑Fi сети**. В гостевых сетях ресторанов устройства иногда изолированы друг от друга. Тогда раздайте интернет с телефона или выложите игру в интернет (см. ниже).

Проверить в одиночку: в лобби выберите «Боты для теста: 3» и зайдите с телефона.

## Выложить в интернет

Подойдёт любой хостинг с Node.js и поддержкой WebSocket: Render, Railway, Fly.io, свой VPS.
- Команда сборки: `npm install`, команда запуска: `npm start`.
- Хостинг сам задаёт `PORT`.
- Если QR-код ведёт не туда, задайте `PUBLIC_URL=https://ваш-адрес`.

Состояние игр хранится в памяти сервера, поэтому нужен **один** экземпляр сервера. При перезапуске текущие комнаты пропадут.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | 3000 | Порт сервера |
| `PUBLIC_URL` | авто | Адрес для QR-кода |
| `T_WRITE` | 45 | Секунд на ложь |
| `T_VOTE` | 30 | Секунд на голосование |
| `T_REVEAL` | 4 | Секунд на одну карточку раскрытия |

## Свои вопросы

В лобби откройте «Свои вопросы про героев вечера». Первая строка — название праздника, дальше по вопросу в строке:

```
Юбилей Ольги Сергеевны
Ольга Сергеевна однажды выиграла в лотерею ___ | живого гуся | путёвку в Сочи; холодильник
На первой работе Ольга Сергеевна была ___ | вожатой в лагере
```

После `|` идёт правда, после второго `|` можно через `;` перечислить ложь для ботов. Готовые наборы лежат в `packs.json`, их можно дополнять.

## Правила и очки

- Угадал правду: **+1000**.
- За каждого, кто поверил твоей лжи: **+500**.
- Если гость случайно написал правду, игра попросит придумать другой вариант.
- Одинаковые выдумки разных гостей склеиваются в один вариант, очки получают оба автора.
- Свой вариант гость при голосовании не видит.
- В финале объявляются «Победитель вечера» и «Мастер блефа» (тот, кто обманул больше всех).

## Ведущему

- **Пробел** или **→** — следующий шаг. Ответы и голоса закрываются сами по таймеру или когда ответили все.
- В лобби нажатие на имя гостя убирает его из комнаты (на случай неприличного ника).
- Если гость перезагрузит страницу или у него пропадёт связь, он вернётся в игру со своими очками.
- Если перезагрузить экран ведущего, комната сохранится.

## Устройство

- `server.js` — комнаты, фазы игры, таймеры, очки, боты (Express + Socket.IO).
- `public/host.html` — большой экран и пульт ведущего.
- `public/play.html` — телефон гостя.
- `packs.json` — наборы вопросов.
- `test/e2e.js` — автотест полной игры: `npm test`.
